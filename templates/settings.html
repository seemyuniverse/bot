봇 쉬는 시간 설정 (한국 시간 기준)

체크를 해제하면 쉬는 시간 제한 없이 24시간 상시 탐사가 진행됩니다. 체크 시 지정된 시간 동안 탐사 대신 아래 안내 문구를 발송합니다.

탐사 결과 문구

문구 안에 아래 표시를 중괄호째 적으면 봇이 답글을 보낼 때 알맞은 내용으로 바꿔 넣습니다. 줄바꿈은 적은 그대로 나갑니다.

  • {acct} : 멘션한 사람의 아이디
  • {region} : 지역 / {zone_grade} : 구역 등급 / {zone_type} : 구역 유형
  • {defeated} : 토벌한 마릿수
  • {body_part} : 부상 부위 / {injury} : 부상 종류 / {injury_obj} : 부상 종류 뒤에 을/를을 붙인 것
  • {loot} : 얻은 보상 이름

지역·등급·부상 등의 후보는 '랜덤 요소' 메뉴에서, 보상은 '아이템' 메뉴에서 고칠 수 있습니다.

동일한 내용의 탐사 결과가 연속으로 발송될 때 마스토돈 스팸 방지 필터에 걸리는 것을 예방합니다.
